# namecard-maker

가로형·세로형 명함을 편집하고 PNG, JPG, SVG 이미지로 저장하는 독립 웹앱입니다.

## 주요 기능

- 명함 방향과 앞면·뒷면 전환
- 텍스트와 회사 CI 선택, 이동, 글자 크기와 정렬 조절
- 시안 더블클릭 문구 편집, Delete 삭제, 실행 취소
- 자동 줄맞춤과 정보 줄맞춤
- 영문·한글 CI 이미지 교체, 크기·회전·반전·자르기
- 걱정인형을 글자 뒤 레이어로 배치
- PNG·JPG·SVG 이미지 저장

## 실행

```bash
pnpm install
pnpm build
pnpm start
```

명함 정보와 업로드 이미지는 브라우저 기기에 저장됩니다. 외부 저장소나 레퍼런스 사이트로 이동하는 링크는 포함하지 않습니다.
