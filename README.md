# namecard-maker

가로형·세로형 명함을 편집하고 PNG·JPG·SVG로 저장하는 독립 웹앱입니다.

## GitHub Pages 배포

`pages/index.html`과 `pages/main.tsx`는 기존 명함 편집 화면을 브라우저에서 직접 실행하는 정적 진입점입니다. `pnpm install --frozen-lockfile` 후 `pnpm build:pages`로 빌드합니다. 필요한 갤러리 이미지는 빌드 전에 검증된 묶음에서 자동 복원합니다.

결과는 `dist-pages/`에 생성되며, 기본 배포 경로는 `/pdf-editor/namecard-maker/`입니다. 다른 경로로 배포할 때는 빌드 전에 `PAGES_BASE_PATH`를 앞뒤 `/`가 있는 경로로 지정하세요. 이미지·글꼴 주소도 같은 경로를 사용합니다. 기존 Sites용 `pnpm build`와 호스팅 설정은 유지합니다.

현재 계정은 비공개 저장소의 Pages를 지원하지 않아 소스는 비공개로 유지하고, `minovation-TF/pdf-editor`의 `namecard-maker/`에 정적 결과물을 게시합니다. 게시 저장소 루트의 `.nojekyll`을 유지해야 합니다.

## 편집 방법

- 요소 클릭: 선택, 더블클릭: 문구 수정
- 모서리 드래그: 이미지 크기와 글자 크기 조절
- 텍스트 상자 양옆 드래그: 상자 너비 조절
- 빈 곳 드래그: 여러 요소를 사각형으로 선택
- Shift+클릭: 선택 추가·해제
- 선택한 요소 드래그: 간격을 유지하며 함께 이동
- Ctrl/Cmd+A: 명함의 표시된 요소 전체 선택
- 방향키: 이동, Shift+방향키: 10배 이동, Delete: 선택 요소 삭제
- Ctrl/Cmd+Z: 실행 취소, Ctrl/Cmd+Shift+Z: 다시 실행

가로형·세로형, 앞·뒷면, 실행 취소·다시 실행을 LIVE PREVIEW 아래 메뉴로 통합했습니다. 더보기 메뉴에서 자동 줄맞춤·정보 줄맞춤·안전선·초기화를 사용할 수 있습니다. 왼쪽 배치 탭 대신 프리뷰에서 객체를 선택하면 편집 도구가 나타납니다. 숫자 입력은 선택한 객체의 ‘세부 조정’에서 사용할 수 있습니다. 왼쪽 편집 패널에는 별도 내부 스크롤을 두지 않았습니다.

## 실행과 GitHub 백업 복원

GitHub 백업에서는 이미지 원본과 미리보기를 `asset-bundles/`의 분할 압축 파일로 함께 보관합니다. 소스 파일은 직접 열고 수정할 수 있으며, 아래 복원 명령으로 모든 이미지를 원래 경로에 풀 수 있습니다. 파일을 합치거나 별도 저장소에 로그인할 필요가 없습니다.

```bash
python3 scripts/restore-assets.py
pnpm install
pnpm build
pnpm start
```

Windows에서는 첫 명령의 `python3` 대신 `python`을 사용하세요. 압축 해제 전에 분할 파일과 전체 압축 파일의 SHA-256을 검증합니다. 이미 이미지가 포함된 체크아웃에서는 복원 단계를 건너뜁니다.

명함 정보와 업로드 이미지는 사용자의 브라우저에 저장됩니다.

## 자격·인증 마크

이미지·CI 탭의 ‘자격·인증 마크’에서 AFPK, CFP 가로형·흰색형, GA 우수인증설계사, MDRT Member를 선택할 수 있습니다. AFPK·CFP·GA 마크는 투명 PNG이며, MDRT는 형태를 유지한 흰 배경 공식 원본입니다. 출처와 사용 안내는 `public/assets/credentials/sources.json`에 기록했습니다. CPA 개인 자격마크와 손해보험협회 우수인증 마크는 확인 가능한 원본을 확보하지 못해 등록하지 않았습니다. GA 마크와 손해보험협회 마크는 서로 다릅니다.

추가 무료글꼴은 사용자 요청에 따라 제외했습니다. 기존 기본 글꼴만 사용합니다. 배경·글자색 기본 팔레트에 업로드 CI에서 확인한 메리츠 레드(#EE3722)를 추가했습니다.

배경 있는 원본 5종은 목록·원본·썸네일에서 삭제했습니다. 과거 백업을 복원할 때도 해당 파일을 제외합니다. 회사 CI 메뉴를 최상단으로 옮겼고, 기본 앞면의 한글 메리츠화재 CI는 제거했습니다. 기존 기본 CI가 남아 있는 저장 명함도 불러올 때 동일하게 정리합니다. 명함 규격은 프리뷰 안쪽 아래에 표시합니다.

## 단순화한 편집 화면

회사 로고는 맨 앞의 독립 탭으로 이동했고, 전체 이미지 목록에 섞이지 않도록 분리했습니다. 한글 메리츠화재·메리츠 파트너스 검정색 투명 버전과 파란 심볼·검정 글자의 CFP 투명 버전을 추가했습니다. 원본 로고는 그대로 선택할 수 있습니다.

배경은 앞·뒷면·방향 선택과 같은 줄의 버튼에서 바꿉니다. 객체 편집은 선택 시 팝업으로 열려 화면 아래에 편집 패널이 쌓이지 않습니다. 텍스트 추가는 문구·크기·색을 팝업에서 정한 뒤 한 번 확인하며, 같은 면에서 추가 버튼을 다시 누르면 기존 추가 텍스트를 수정합니다. 이전의 반복 생성된 기본 ‘새로운 문구’는 하나로 정리하되, 사용자가 작성한 다른 문구는 보존합니다.
